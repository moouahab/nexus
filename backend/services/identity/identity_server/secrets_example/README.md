# Secrets Example

Copy this directory to `secrets/` for local development, then replace every
placeholder value with real local values.

```bash
cp -r secrets_example secrets
```

Required for local Vault development:

- `vault_dev_root_token`: root token used only by the local dev Vault server
- `vault_role_id`: AppRole role id generated by Vault
- `vault_secret_id`: AppRole secret id generated by Vault

Required for the test Compose profile:

- `postgres_test_password`
- `redis_test_password`

Production AppRole examples live under `production/`. Real production values
must come from the deployment platform secret store, not from committed files.

Do not commit the real `secrets/` directory.
