# NEXUS — UI / UX Login Kit

Ce dossier contient les versions haute qualité de la page de connexion NEXUS.

## Structure

- `00_REFERENCE` : images de référence originales
- `01_DESKTOP` : Light / Dark
- `02_TABLET`
  - `LANDSCAPE` : Light / Dark
  - `PORTRAIT` : Light / Dark
- `03_MOBILE` : Light / Dark
- `04_BACKGROUNDS` : backgrounds seuls Light / Dark
- `05_EXPORTS_WEBP` : versions WebP optimisées
- `06_DOCS` : manifest et notes

## Direction visuelle

- Cyber-tech minimaliste
- Pas de cards flottantes
- Pas de glassmorphism
- Rouge utilisé en accent
- Google monochrome
- Lignes fines et motifs circuits discrets
- Version Light et Dark cohérentes

## Important

Les fichiers PNG présents dans les dossiers principaux sont les masters générés pour cette version du kit.
