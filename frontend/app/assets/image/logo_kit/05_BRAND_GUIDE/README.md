# NEXUS — Vector Logo Kit V2

## Pourquoi cette version est meilleure
La première version venait d’une petite image raster de 290×220 px.
Un simple agrandissement crée forcément du flou et de la pixellisation.

Cette V2 a été reconstruite en **vectoriel** à partir du logo validé :
- symbole N géométrique redessiné en formes vectorielles ;
- wordmark NEXUS converti en contours vectoriels ;
- aucune dépendance à une police dans les fichiers SVG ;
- exports PNG jusqu’à 4096 px ;
- fond transparent.

## Couleurs
- NEXUS Red : #ff3137
- Deep Red : #d50f18
- Deep Black : #0c0c0e
- White : #f5f5f6
- Neutral Gray : #8f9098

## Usage
- SVG : Figma, web, UI/UX, impression, responsive.
- PNG 4096 : présentations, réseaux, mockups, vidéo.
- Icône seule : favicon, app icon, avatar.
- Version blanche : fond sombre.
- Version noire : fond clair.
- Version couleur : usage principal.

## Règles
- Ne pas étirer.
- Ne pas modifier l’angle ou les proportions du N.
- Ne pas ajouter d’ombre portée forte.
- Conserver de l’espace autour du logo.
- Pour le site Nexus, privilégier le logo couleur sur fond #0C0C0E.
