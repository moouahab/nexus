# NEXUS — Background System UI/UX

Ce dossier contient un système de backgrounds cohérent pour tout le site NEXUS.

## Variantes

### 01_BG_HERO
À utiliser pour :
- page de login
- register
- landing
- pages d'entrée importantes

Style :
- identité visuelle la plus forte
- N transparent visible
- circuits rouges plus présents
- effet premium / signature Nexus

### 02_BG_PAGE
À utiliser pour :
- pages standard du site
- pages projets
- sections produit
- pages de présentation

Style :
- même ADN visuel
- plus discret que HERO
- meilleur équilibre entre personnalité et lisibilité

### 03_BG_CLEAN
À utiliser pour :
- dashboard
- tableaux
- pages avec beaucoup de texte
- pages settings / admin

Style :
- très léger
- peu de contraste décoratif
- contenu prioritaire

## Recommandation

Ne pas utiliser exactement le même fond partout.
Utiliser ce système :
- HERO = entrée / branding
- PAGE = navigation courante
- CLEAN = contenu dense

## Modes
Chaque variante existe en :
- Light
- Dark
